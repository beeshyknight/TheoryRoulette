# Theory Roulette — Rabbit r1

This build is deliberately flat for maximum r1 importer compatibility. `index.html`, CSS, JavaScript, data and PNG artwork all live in the same project folder, so the Creation does not depend on nested folder extraction.

Controls: wheel = move through choices/cards; side button = select/draw/continue; long press = reflection challenge; shake = wildcard where supported.

Content: 100 cards (55 informing theories/lenses, 45 intervention/practice approaches), 40 practice situations, 16 wildcards and 16 changing-information modifiers.
